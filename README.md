# Transam Tuscan
Resource for vintage Tuscan-S100 computer 
 
 
### Directory

* [MITSI](MITSI) - monitor source and binary files 
* [RAM TEST](RAM_TEST) - tests without needing any good ram
* [CON TEST](CON_TEST) - screen echo programs for testing simulator
* Z80SIM - configured with Tuscan ports for I/O
* [Disks - CP/M archive](disks)
* images - pictures
* [Mitsi Mon Scans](images/MitsiMonScans/README.md)
